# CyberSnapper 2.4.0 (2026-09-06)

CyberSnapper 2.4.0 adds paired light/dark website screenshots and makes capture output easier to follow and find.

## Website themes

- Choose **Light**, **Dark**, or **Both** on Capture or in the profile editor.
- Set the browser's `prefers-color-scheme` preference before loading each page in a fresh context. Websites must support that preference to look different.
- Keep light and dark originals, portfolio copies, and comparison baselines separate. Existing light baselines remain usable.
- Include both themes in the capture plan and the 10,000-file job limit.

## Filenames and output access

- Default filenames include the host, page path, and viewport: `https://example.com/sample` becomes `example.com-sample-Desktop.png`.
- Paired captures use `-light` and `-dark` suffixes. Custom templates support `{colorScheme}` in filenames or subfolders, with a fallback suffix if a long name truncates the token.
- Upgrade the previous exact default filename template while preserving other custom templates. Existing files are not renamed.
- Open the active project's captures directory from **Open Output Folder** at the top of Capture.

## Live progress

- Show capture position, URL, viewport, browser, theme, and the task currently running.
- Report loading, settling delays, content filtering, cookie-banner handling, scrolling, screenshot capture, file writes, portfolio rendering, and comparisons.
- Update elapsed stage time every two seconds and processed-file counts after each output, including skips and failures.
- Track parallel tasks separately, replay persisted progress on reconnect, and handle cancellation and terminal states.

## Verification

- Worker typechecking and 39 worker tests, including a real Chromium light/dark fixture.
- Native core, GUI, and CLI checks, including profile normalization, theme-aware limits, and progress event handling.
- Deterministic before/after Capture screenshots and the documentation site build.
- The release workflow smoke-tests packaged browser installation and real capture on Linux, Windows, and macOS for x64 and arm64.
