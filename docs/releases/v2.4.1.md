# CyberSnapper 2.4.1 (2026-09-06)

## More room on Capture

- Smaller buttons and tighter spacing without shrinking text.
- Remove repeated help-text rows; retain guidance in tooltips.
- Show comparison details only when change monitoring is enabled.
- Keep capture actions, progress, and output-folder access outside scrollable settings on shorter windows.

## Clean screenshot edges

- Remove reserved root scrollbar gutters before preparation and capture. This fixes the blank right-edge strip on sites that reserve scrollbar space even though screenshots hide the scrollbar.
- Preserve the requested viewport and image dimensions; no edge cropping or image resizing.

## Skip identical dark outputs

- In Both mode, compare exact rendered PNG bytes with the successfully saved light capture before encoding, writing, or rendering dark portfolio copies.
- Omit identical dark output files and adjust the progress total automatically. The completion message reports the omitted files.
- Each theme still loads in its own fresh browser context to verify the result; this is not a CSS-only dark-mode detection heuristic.
- Retain both themes for PDF jobs, failed or reused/skipped light outputs, and existing dark comparison baselines. Dark-only captures are unchanged. Existing files are never deleted.

## Verification

- Real-browser fixtures cover scrollbar gutters, identical and distinct themes, dark-only output, existing baselines, concurrent targets, skipped files, failures, and cancellation.
- Native checks cover the 1024 × 600 Capture layout and progress totals that shrink after duplicate detection.
- Live verification on Cabos Fishing, JWDM, and 2A Transfers removed the white strip and saved three distinct images instead of six redundant outputs.
- Release packages are smoke-tested on Linux, Windows, and macOS for x64 and arm64.
