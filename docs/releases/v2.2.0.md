# CyberSnapper 2.2.0

CyberSnapper 2.2 turns visual comparison into a full review workflow and makes reusable target collections a first-class part of every capture surface.

## Highlights

- Dashboard with clear counts for review work, failed or partial runs, active jobs, and the next schedule.
- Named target sets with labels, ordering, enable controls, bulk paste, and TXT/CSV import/export.
- Target-set snapshots shared by captures, schedules, retries, CLI, and REST automation.
- Review queue with accepted, ignored, and unreviewed decisions; notes; filters; search; batch actions; and A/I/U shortcuts.
- Plain-language change summaries backed by exact analyzed/mismatched pixel counts and changed-region metadata.
- Large synchronized baseline/current viewers with Fit, analyzed 100%, pan, zoom, overlay, wipe, and generated diff modes.
- Immutable baseline evidence and optimistic review revisions that prevent accidental stale updates.
- Adaptive customizable toolbar, always-available menus, resettable UI state, and compact self-documenting Capture controls.
- SQLite schema v4 and expanded dashboard, target-set, comparison, and review automation APIs.

## Packages

- `CyberSnapper-macos-arm64.zip` — macOS Apple silicon
- `CyberSnapper-macos-x64.zip` — macOS Intel
- `CyberSnapper-windows-x64.zip` — Windows x64
- `CyberSnapper-linux-x64.tar.gz` — Linux x64
- `SHA256SUMS.txt` — SHA-256 checksums for release archives

The workflow also publishes GitHub/Sigstore build-provenance attestations. macOS packages use ad-hoc signing; Windows packages are currently unsigned.

## Compatibility

Schema-v2 and schema-v3 CyberSnapper projects are upgraded transactionally when opened. CyberSnapper 2 remains a clean break from 1.x; the frozen original source and download are available from the [v1.0.0 release](https://github.com/Alex9001/CyberSnapper/releases/tag/v1.0.0).
