# CyberSnapper 2.2.0

CyberSnapper 2.2 makes the core screenshot workflow a portfolio studio. Capture a website across desktop, tablet, and phone sizes, then turn those captures into presentation-ready images without leaving the native application or uploading the work to a template service.

## Highlights

- Portfolio style saves both the untouched capture and a polished `-portfolio` copy, keeping the original available for reuse and comparison.
- Clean, Aurora, Sunset, Midnight, Graphite, and custom-solid scenes provide ready-made presentation backgrounds.
- Browser, tablet, phone, rounded-card, automatic, and frameless treatments cover desktop and responsive portfolio work in light or dark styles.
- Fit-content, 16:9, 4:3, and square canvases combine with adjustable padding and shadows without cropping or upscaling the source screenshot.
- Automatic framing chooses browser chrome for desktop viewports, tablet or phone hardware for mobile-mode captures, and a rounded card for full-page or element captures.
- The native Capture workspace keeps URLs, saved portfolio projects, viewport choices, capture modes, browser engines, formats, and page cleanup controls close together and explains unfamiliar options in place.
- Full-page, viewport, and CSS-selected element captures can be produced across desktop, tablet, mobile, and custom sizes in the same run.

## Supporting power tools

- Named target sets add labels, ordering, enable controls, bulk paste, and TXT/CSV import/export for portfolios with many projects or pages.
- The Review workspace adds accepted, ignored, and unreviewed decisions; notes; filters; search; batch actions; keyboard shortcuts; and synchronized fit, pan, zoom, overlay, wipe, and difference views.
- Plain-language change summaries retain exact analyzed and mismatched pixel counts, changed-region metadata, and immutable baseline evidence.
- The Dashboard, schedules, retries, CLI, and authenticated local REST API support recurring and automated work without getting in the way of one-off portfolio capture.
- The local REST API now reports its configured listening port correctly, so generated automation credentials connect to the service that issued them.
- SQLite schema v4 carries normalized target provenance, comparison analysis metadata, reviews, and target-set schedules.

## Packages

- `CyberSnapper-macos-arm64.zip` — macOS Apple silicon
- `CyberSnapper-macos-x64.zip` — macOS Intel
- `CyberSnapper-windows-x64.zip` — Windows x64
- `CyberSnapper-linux-x64.tar.gz` — Linux x64
- `SHA256SUMS.txt` — SHA-256 checksums for release archives

The workflow also publishes GitHub/Sigstore build-provenance attestations. macOS packages use ad-hoc signing; Windows packages are currently unsigned.

## Compatibility

Schema-v2 and schema-v3 CyberSnapper projects are upgraded transactionally when opened. CyberSnapper 2 remains a clean break from 1.x: it does not import or depend on 1.x state, and no migration path is provided. The frozen original source and download remain available from the [v1.0.0 release](https://github.com/Alex9001/CyberSnapper/releases/tag/v1.0.0).
