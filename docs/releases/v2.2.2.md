# CyberSnapper 2.2.2

CyberSnapper 2.2.2 makes the Chromium capture engine more reliable by transparently using a system browser when the bundled Chromium is unavailable or, on Windows arm64, running under emulation.

## Highlights

- The Chromium engine now falls back to Google Chrome and then Microsoft Edge when the bundled Chromium is missing.
- On Windows arm64, an x64 (emulated) bundled Chromium is replaced by a native system Chrome or Edge when one is installed.
- The fallback is automatic and needs no configuration, on Windows, Linux, and macOS.

## Packages

CyberSnapper 2.2.2 ships the same twelve packages as 2.2.1:

| Platform | Recommended | Portable |
| --- | --- | --- |
| Linux x64 | `CyberSnapper-linux-x64.AppImage` | `CyberSnapper-linux-x64.tar.gz` |
| Linux arm64 | `CyberSnapper-linux-arm64.AppImage` | `CyberSnapper-linux-arm64.tar.gz` |
| Windows x64 | `CyberSnapper-windows-x64-setup.exe` | `CyberSnapper-windows-x64-portable.zip` |
| Windows arm64 | `CyberSnapper-windows-arm64-setup.exe` | `CyberSnapper-windows-arm64-portable.zip` |
| macOS Intel | `CyberSnapper-macos-x64.dmg` | `CyberSnapper-macos-x64.zip` |
| macOS Apple silicon | `CyberSnapper-macos-arm64.dmg` | `CyberSnapper-macos-arm64.zip` |

`SHA256SUMS.txt` contains checksums for all twelve packages, and each package carries a GitHub/Sigstore build-provenance attestation.

## Signing

Signing is unchanged from 2.2.1: macOS application bundles are ad-hoc signed but not Apple-notarized, and Windows installers and Linux packages are unsigned. SHA-256 checksums and provenance attestations let every download be verified independently.

## Compatibility

CyberSnapper 2.2.2 uses the same project format as 2.2.0 and 2.2.1. CyberSnapper 2 remains a clean break from 1.x: it does not import or depend on 1.x state, and no migration path is provided. The frozen original source and download remain available from the [v1.0.0 release](https://github.com/Alex9001/CyberSnapper/releases/tag/v1.0.0).
