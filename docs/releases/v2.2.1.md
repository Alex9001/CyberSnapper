# CyberSnapper 2.2.1

CyberSnapper 2.2.1 makes the native application straightforward to download on current x64 and arm64 computers. Each supported operating system now has an install-friendly package as the recommended choice and a portable archive for people who prefer a no-install layout.

## Highlights

- Linux x64 and arm64 builds ship as AppImages, with portable tar.gz archives available alongside them.
- Windows x64 and arm64 builds ship as setup executables, with portable ZIP archives available alongside them.
- macOS Apple silicon and Intel builds ship as DMGs, with ZIP archives available alongside them.
- Every package bundles the Qt runtime, Node runtime, capture worker, and Chromium needed for the core screenshot workflow.
- Package smoke tests cover the native application and packaged CLI before release assets are published.

## Packages

| Platform | Recommended | Portable |
| --- | --- | --- |
| Linux x64 | `CyberSnapper-linux-x64.AppImage` | `CyberSnapper-linux-x64.tar.gz` |
| Linux arm64 | `CyberSnapper-linux-arm64.AppImage` | `CyberSnapper-linux-arm64.tar.gz` |
| Windows x64 | `CyberSnapper-windows-x64-setup.exe` | `CyberSnapper-windows-x64-portable.zip` |
| Windows arm64 | `CyberSnapper-windows-arm64-setup.exe` | `CyberSnapper-windows-arm64-portable.zip` |
| macOS Intel | `CyberSnapper-macos-x64.dmg` | `CyberSnapper-macos-x64.zip` |
| macOS Apple silicon | `CyberSnapper-macos-arm64.dmg` | `CyberSnapper-macos-arm64.zip` |

`SHA256SUMS.txt` contains checksums for all twelve packages. The release workflow also publishes GitHub/Sigstore build-provenance attestations for each package.

## Signing

The macOS application bundles are ad-hoc signed but not Apple-notarized. The Windows setup executables and Linux packages are currently unsigned. SHA-256 checksums and provenance attestations let every download be independently verified without requiring paid platform signing identities.

## Compatibility

CyberSnapper 2.2.1 uses the same project format as 2.2.0. CyberSnapper 2 remains a clean break from 1.x: it does not import or depend on 1.x state, and no migration path is provided. The frozen original source and download remain available from the [v1.0.0 release](https://github.com/Alex9001/CyberSnapper/releases/tag/v1.0.0).
