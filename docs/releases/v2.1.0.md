# CyberSnapper 2.1.0

CyberSnapper 2.1 turns the original screenshot utility into a native, local-first visual QA application for macOS, Windows, and Linux.

## Highlights

- Native Qt interface for Capture, History, Compare, Schedules, Settings, and in-app Help.
- Persistent background agent with a durable capture queue, crash recovery, and recurring schedules.
- Chromium, Firefox, and WebKit captures through a private Playwright worker.
- Full-page, viewport, and CSS-element modes with PNG, WebP, AVIF, and Chromium PDF output.
- Reusable profiles for viewports, delays, selectors, popup blocking, formats, naming, and concurrency.
- Visual baselines, configurable mismatch thresholds, generated diffs, side-by-side review, and overlays.
- Native CLI and authenticated localhost REST API sharing the GUI's projects, jobs, and artifacts.
- Portable folder projects containing captures, baselines, diffs, a readable manifest, and SQLite history.
- Once, interval, daily, weekly, and monthly schedules with IANA time zones.
- Clearer high-contrast controls, compact Capture layout, self-documenting viewport controls, and Ready status.

## Packages

- `CyberSnapper-macos-arm64.zip` — macOS Apple silicon
- `CyberSnapper-macos-x64.zip` — macOS Intel
- `CyberSnapper-windows-x64.zip` — Windows x64
- `CyberSnapper-linux-x64.tar.gz` — Linux x64
- `SHA256SUMS.txt` — SHA-256 checksums for release archives

The workflow also publishes GitHub/Sigstore build-provenance attestations. macOS packages use ad-hoc signing; Windows packages are currently unsigned.

## About 1.x

CyberSnapper 2 is a clean break. It does not import or depend on 1.x configuration or state, and no migration is required. The original source and download remain frozen in the [v1.0.0 release](https://github.com/Alex9001/CyberSnapper/releases/tag/v1.0.0).
