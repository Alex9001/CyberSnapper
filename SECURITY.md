# Security policy

## Supported versions

Security fixes are made for the latest stable CyberSnapper 2.x release only.

| Version | Supported |
| --- | --- |
| Latest stable 2.x release | Yes |
| Earlier 2.x releases | No |
| 1.x and earlier | No |

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/Alex9001/CyberSnapper/security/advisories/new)
so the report and any supporting material remain private.

Include the affected version and platform, reproduction steps or a proof of
concept, the expected impact, and any known mitigations. The maintainers will
coordinate investigation and disclosure through the private advisory.
