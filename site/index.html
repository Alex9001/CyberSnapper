A faster portfolio workflow

From URL to finished image set in three steps.

  1. 01

    Add your work

    Paste one or more website URLs, or save a labeled target set for the projects and pages you capture repeatedly.

  2. 02

    Choose the presentation

    Select full-page, viewport, or element capture; add the exact desktop, tablet, and mobile sizes; then choose formats, scene, frame, canvas, and clean-up rules.

  3. 03

    Capture and publish

    Run the batch once. Open the finished files from History and drop the consistent image set into your portfolio, case study, or client gallery.

Local-first architecture

Your captures remain your files.

Projects are ordinary portable folders backed by SQLite. The Qt interface talks to a local background agent; a private Playwright worker drives browsers only when a capture runs.

  • No hosted account or cloud dependency
  • API binds only to 127.0.0.1 and is off by default
  • Private-network navigation protections and pinned DNS resolution
  • Readable project manifest, captured images, and history
